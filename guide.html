Transférer des ressources entre logiciels

Library → Engine : modèle GLB et prefab

Ouvrir Library → Prefab Studio. Choisir un modèle GLB réel, configurer ses composants et cliquer sur « Installer dans Engine ». Le transfert direct utilise une fenêtre Engine et un échange de messages entre origines vérifiées. En alternative, exporter le .wlpkg.json puis l'importer dans Engine. Engine conserve le modèle dans IndexedDB et le prefab localement. Une version en conflit nécessite confirmation. Les scripts référencés ne sont pas automatiquement livrés dans le pack individuel. Utilise Pack Builder pour envoyer plusieurs PNG, GLB et scripts ; les scripts sont stockés, puis importables explicitement depuis Script Studio sans exécution automatique. Les scènes existantes ne sont pas migrées.

Node → Monteur : effets

Choisir « Envoyer à Monteur » dans Node puis sélectionner un clip dans Monteur pour recevoir le graphe. Le format warlike-node-effect version 1 conserve les nœuds, connexions, masques et animations. Monteur calcule via Canvas2D les graphes à source média unique : corrections couleur, masques, détourage chroma, flou, fusion de couches, RGB et keyframes. Les graphes avec plusieurs sources indépendantes restent conservés mais leur rendu et export sont refusés.

Autres fichiers : transfert manuel

Exporter un fichier depuis sa source puis l'importer dans l'application cible. Aucun espace de stockage commun entre domaines n'est garanti. Préférer les formats PNG, GLB auto-contenu, WAV, MIDI, WebM et les JSON WarLike versionnés selon le logiciel. Toujours vérifier les licences et conserver les médias originaux : plusieurs projets JSON mémorisent les références mais pas les octets.

Sauvegarde et sécurité

Ne confonds pas « sauvegardé dans le navigateur » et « synchronisé dans le cloud ». Un changement de domaine, profil ou appareil ne transporte pas les fichiers locaux. Effectue des exports réguliers et teste la restauration avant toute suppression de données.

Vérifier les autorisations des ressources ; ne jamais exécuter un script importé sans inspection. Crypte est un outil expérimental et non une solution unique de conservation d'identifiants sensibles.

Résoudre les incidents courants

Un modèle 3D est absent, gris ou incomplet

Vérifier que le GLB est au format 2.0, contient des maillages et embarque ses textures/buffers. Les dépendances externes sont refusées par l'import de prefabs Engine. Contrôler WebGL et les noms exacts des pièces articulées.

Le transfert direct n'ouvre pas l'application

Autoriser l'ouverture explicite de la fenêtre pour le domaine WarLike concerné. Vérifier la disponibilité des deux sites et les erreurs affichées. Utiliser l'export/import manuel si le transfert direct échoue ; aucun fichier n'est transmis à un serveur central.

L'export vidéo ne démarre pas

Vérifier la présence de médias locaux, la compatibilité WebM/MediaRecorder et les graphes Node. Les graphes à plusieurs sources indépendantes ou nœuds non reconnus sont refusés avant export.

Un projet ne retrouve pas ses médias

Réimporter les fichiers sources avant le projet JSON, lorsque le logiciel fonctionne par références. Vérifier que les noms, tailles et formats correspondent.
